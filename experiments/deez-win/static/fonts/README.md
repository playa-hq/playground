# Excalifont

The bundled `.woff2` files are the unmodified Excalifont webfont subsets from
the Excalidraw project. Excalifont is licensed under the SIL Open Font License
1.1; its licensing metadata is embedded in each font file.

Source: https://github.com/excalidraw/excalidraw/tree/master/packages/excalidraw/fonts/Excalifont
